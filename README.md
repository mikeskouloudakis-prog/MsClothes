# MsClothes – Fashion Website

MsClothes is an academic web development project created as part of my Computer Science studies. It presents a static fashion e-commerce website concept with separate sections for men's and women's clothing, shoes, accessories, lifestyle content, company information, and contact details.

## Features

- Multi-page website with navigation between the main sections
- Men's and women's clothing, shoes, and accessories pages
- Lifestyle and fashion-related articles
- Company information and contact page
- Image and video assets
- Shared CSS stylesheet for the website's visual presentation

## Technologies

- HTML5
- CSS3

## Project scope

This is a front-end academic project. Product information and page content are static. It does not include a server-side application, database, shopping cart, checkout, or functional order processing.

## Running the project

1. Download or clone this repository.
2. Open `MsClothes.html` in a web browser.
3. Navigate through the website using the page menu.

No build tools or package installation are required.
